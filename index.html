Sistema de Automatización de Operaciones

Preparado para: Sr. Mario Cedeño  ·  El Dealer

1 Resumen Ejecutivo
El presente documento describe la propuesta de Devlabs para el desarrollo de un Sistema de Automatización de Operaciones diseñado a la medida del negocio de El Dealer. El objetivo es transformar el flujo de trabajo actual —completamente manual y gestionado a través de WhatsApp— en un proceso inteligente, automatizado y trazable que elimine el riesgo de error humano, reduzca los tiempos de respuesta al cliente y brinde al equipo información en tiempo real para la toma de decisiones.

3 El Problema que Resolvemos
  • ⏱️
    Operación lenta y dependiente de personal. Cada solicitud requiere que un operador revise manualmente el WhatsApp, valide el comprobante, verifique duplicados y notifique al cliente. El volumen crece, pero el equipo no puede escalar al mismo ritmo.
  • ⚠️
    Riesgo económico por validación manual. La verificación de comprobantes falsos o duplicados depende del criterio humano. Un error en este paso tiene consecuencias financieras directas para el negocio.
  • 📊
    Cero visibilidad del negocio. No existe un registro consolidado de transacciones ni métricas que permitan entender el volumen de operaciones, los picos de demanda o el rendimiento del equipo.
  • 🔔
    Experiencia deficiente para el cliente final. Los tiempos de respuesta dependen de la disponibilidad del operador, generando incertidumbre sobre el estado de cada transacción.

4 Alcance del Proyecto — Módulos a Desarrollar
M1
Canal Automatizado de WhatsApp
Integración con Green API
2 semanas
  • Recepción automática y clasificación del tipo de solicitud (depósito / retiro)
  • Flujo de conversación guiado para captura de datos del cliente
  • Notificaciones automáticas de estado en cada etapa del proceso
  • Confirmación final al cliente una vez procesada su solicitud
M2
Motor de Validación de Comprobantes
OCR + Verificación cruzada con correo bancario
3 semanas
  • Extracción automática de datos del comprobante enviado por WhatsApp mediante OCR
  • Lectura del correo bancario para obtener la notificación oficial del banco
  • Verificación cruzada de fecha, monto e ID de transacción entre ambas fuentes
  • Soporte para 1 banco principal en esta versión (ampliable en fases futuras)
M3
Sistema Anti-Duplicados y Trazabilidad
Control de unicidad y estados de transacción
0.5 semanas
  • Detección automática de comprobantes ya procesados con anterioridad
  • Registro de huella digital (hash) de cada comprobante como respaldo
  • Ciclo de vida completo: Recibida → En validación → Procesada / Rechazada
  • Historial auditable de todas las transacciones
M4
Plataforma Web Operativa y Dashboard
React + ElysiaJS + PostgreSQL
6 semanas
  • Panel de control en tiempo real con estado de todas las solicitudes activas
  • Alertas internas al equipo cuando ingresa una nueva solicitud
  • Historial completo con filtros por fecha, tipo y estado
  • Estadísticas de operación: diario, semanal, mensual y anual
  • Sistema de autenticación y control de acceso por roles
  • Diseño responsivo: accesible desde computador o dispositivo móvil
M5
Análisis, Diseño, QA y Puesta en Producción
Planificación · Pruebas · Despliegue · Capacitación
3 semanas
  • Levantamiento de requerimientos y diseño de flujos de usuario (UX/UI)
  • Pruebas funcionales y de integración sobre todos los módulos
  • Configuración del servidor y despliegue en ambiente de producción
  • Capacitación al equipo operativo de El Dealer
